# f2x-flypass/.github

Archivos por defecto de la organización en GitHub.

- `pull_request_template.md`: plantilla de PR por defecto para los repositorios que **no** tienen plantilla propia. Si un repositorio tiene la suya, GitHub usa la del repositorio.

## Bloque "Uso de IA"

Lo lee el PreReview Bot como declaración de uso de IA (`declaracion-ia-v1`). Marca las herramientas que usaste o **Ninguna**. Llenarlo no bloquea el PR. Si no marcas nada, el bot registra "sin declaración" y lo muestra en el resumen de la review.

Si tu repositorio tiene plantilla propia, copia el bloque tal cual (el encabezado `## Uso de IA` y las casillas) para que el bot lo lea.

Referencias: `f2x-flypass/prereview-bot` (`specs/009-ai-declaration-signal-coverage`).

Este repositorio es público porque GitHub lo exige para aplicar los archivos por defecto. No contiene código ni datos.
